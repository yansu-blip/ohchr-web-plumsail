# OHCHR Web Plumsail JS Modules

Reusable JavaScript modules for Plumsail forms and web automation workflows.

## Structure
- /modules → reusable JS functions
- /utils → helpers (validation, formatting, etc.)
- /examples → usage snippets

## Usage
Import functions into Plumsail forms via CDN (jsDelivr / GitHub).

## Notes
- Designed for Kendo UI / Plumsail environment
- Integrated with SharePoint & Power Automate flows
